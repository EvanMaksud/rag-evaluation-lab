# Sources

The repository includes a downloader for a reproducible public evaluation corpus.

`scripts/download_public_corpus.py` downloads plain-text extracts from Wikipedia through the public MediaWiki API. Downloaded text is not committed to the repository. Each downloaded document includes its source URL and a short license note.

Wikipedia text is available under CC BY-SA. When using the downloaded corpus outside local experiments, keep the source links and review the license terms on the original pages.
